# Short conversations

Six complete everyday exchanges, 24–32 seconds each. They can run between longer episodes without requiring a narrator or a product demonstration. Each has a setup, a small choice, an actual reply and a visual ending.

Draft v1, 5 November 2026. Written plans only. Each file includes the purpose, cast/wardrobe/location, exact timed shots, physical acting, dialogue, copyable prompts, sound, voice ledger and replaceable batch map.
