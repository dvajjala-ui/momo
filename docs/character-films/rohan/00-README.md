# Rohan — Weekend refresh

**Detailed long-form production brief** · 5 November 2026 · **Working runtime: 2:40 / 160 seconds** · **32 shots, six editable batches** · Original adult character, 28.

Rohan ends Friday with an ordinary paper/printer problem and a humane little joke, then deliberately puts work away. Saturday is a separate day, not an impossible step through office doors into another morning. A friend has their own plans, so Rohan chooses a clear public board-game-and-food plan, asks a practical question and learns by taking a turn. His paper-aligning habit becomes a gentle recurring visual motif. The payoff is a shared laugh and a forgotten score, not a personality being fixed.

The script expands the pulled short-film source into a deliberately slower character film over two minutes. The original premise is preserved; specific face/wardrobe details and the expanded scenes are working proposals awaiting review. No finished movie, voice recording, generated character sheet or approved real event is claimed by these documents.
