## Batch acceptance and alternate cuts

Review one shot first, then the current batch. A useful correction names a visible problem: wrong bag side, listener speaking, short handoff, coat already dry, face changed, chair on wrong side. Do not fix a static pose by adding a larger camera zoom. The person needs a more readable physical action.
The full episode is 144 seconds. A shorter teaser is a separate edit from accepted material; preserve setup, choice and payoff. Remove a complete optional pause or secondary observation before cutting the essential reaction. Any removed shot requires the new adjacent prop/pose states to match. Keep this master timeline intact and record a separate duration map for the short cut.
