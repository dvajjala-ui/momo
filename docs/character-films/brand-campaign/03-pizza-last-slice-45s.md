## Purpose and story

Show an easy, considerate food-table connection without competition, forced generosity or fake social proof. Pizza texture matters, but people carry the story.

One remaining shared slice → ask before taking → optional split → tiny knife problem solved → possible next activity → clear pizza edition sign-off.
