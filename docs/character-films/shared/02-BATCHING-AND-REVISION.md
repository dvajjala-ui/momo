# Small batches, scene continuity and easy length changes

The film runtime is an editing plan, not a demand for one long generation. These new scripts deliberately support small replaceable takes and reviewed batches. Earlier tests from one service sometimes produced static five-second takes; that experience does not prove every short action fails or that a whole film must be generated in one request. Review observable movement, not the method's label.

## Production unit

- **Film:** the whole two-plus-minute story.
- **Scene:** one location/time and dramatic purpose.
- **Batch:** roughly 20–35 edited seconds, often four to seven shots, with one review goal.
- **Shot:** one main visible action and a defined start/end state. A shot can contain a deliberate small cut only when documented.
- **Raw take:** generated/recorded source, often longer than the selected edit. A one-second panda insert is an edit length, not a claim about accepted raw durations.
- **Line:** separately replaceable voice clip identified by the character's line ID.

Every lead folder uses `00` through `06` for reading order: overview, character bible, story, shots, voice/sound, batches/continuity, decisions/revision history. The new files do not overwrite older short-cut notes or original assets.

## Review gates

| Gate | Concrete review item | What is allowed to proceed |
|---|---|---|
| D0 | Adult identity, face/body/hair, front/side/back outfit, palette, reference | Story review can proceed while visuals remain proposed; do not claim a final generated sheet |
| V0 | Heard voice audition and pronunciation on three short samples | Voice casting for the lead; not automatic all-film paid generation |
| B1 | First action batch: moving body and props, consistent room/light, accepted voice test | The next planned batch, keeping all accepted sources |
| B2–B5/6 | Batch goal, shot continuity, line timing, readable edited text, end state | Next batch or a specific correction; do not regenerate accepted earlier actions |
| E1 | Rough assembly: story rhythm, one-day/multi-week logic, no missing decision/payoff | Focused trims/extensions and sound/text finish |
| F1 | Full playback, dialogue/ambience, no accidental product claims, source/rights records | Reviewable final export only after owner approval; publication is separate |

These are practical editorial review gates, not new permission barriers for writing. The current request authorizes all the planning files now. No actual video, voice charge, upload, send or publication is performed here.

## Shot handoff card

```text
film / shot / batch:
script version:
purpose:
camera and frame:
start pose and object positions:
one main action:
end pose and object positions:
wardrobe / hair / face / body reference:
location / light / story time:
line IDs / intended silence:
sound and screen-text inserts:
raw take version / selected edit in-out:
accepted by / review date:
change required:
downstream shots affected:
```

Never use a screenshot of a rejected face as an unquestioned next-frame reference. Matching the previous end frame is useful only if that frame was actually accepted. A deliberate angle cut may require a new consistent starting frame rather than forcing a physically impossible camera movement.

## Changes and their scope

| Change | Usually affected | Usually preserved |
|---|---|---|
| One word/pronunciation | That line's audio and visible mouth timing, possibly its picture hold | Other scenes, costume, location and good silent action |
| A longer breath or pause | The shot hold, adjacent transition and later edit timecodes | The raw accepted take, earlier plot decisions |
| Cap/postcard/phone lettering | Edited graphic insert and tracking where necessary | Character face/body and unrelated motion |
| Sleeve or hand failure | The particular object action, its start/end reference | Other shots in the dressing batch |
| Outfit color/detail | All shots after that costume starts, matching mirror/cameo details | Earlier home/sport/work wardrobe scenes |
| Face/body/hair redesign | All dependent shots for that identity | Reusable location plates, brand graphics, story structure; review as a larger version |
| Meetup time/place/cost | Script logistics and edited plan/card/clock/travel cues | Unrelated close-ups that do not encode those facts |
| Target film length | Selected edit ranges, optional inserts, transitions, score/voice windows | Original takes and the emotional cause-and-effect chain |

## Shorten without breaking the story

First trim repeated setup, redundant screen taps, extra outfit jokes, repeated notifications and optional scenic holds. Keep a desire, a readable choice, a physical departure and a shared payoff. Tara's invitation line and mirror reassurance, Meera's earned multi-week friendship/performance payoff, Sameer's patient urban plan, Gary's welcome, Dhwani's post-dance food moment and Rohan's work-to-weekend transition should still be understandable.

A future 30–45-second cut is a different edit of accepted material. It is not the master duration and must not overwrite the long screenplay. Never create the short version by making every line sound twice as fast.

## Extend without filler

Add a distinct movement, listener response, clear venue/logistics insert, a settling breath, real preparation action or a moment of shared humor. State the extra shot's purpose and version its IDs; avoid extending by a random orbit around an unmoving character. Longer card/consent screens may be necessary for readability, even if the master moves beyond its initial second count.

## File/version convention

Use character and shot IDs, then version/take: `TA20_v01_take01`, `SA08_v02_take02`. Keep a selected-source record rather than repeatedly overwriting `final.mp4`. No raw media is created by this pack. A future version log records actual duration, aspect, frame rate, reference image, selected voice, prompt changes and costs only when those facts exist; do not invent settings or “accepted” statuses in advance.

## End-of-batch checks

Check face/body/hair, garment construction and transitions; hands/feet/props; real action; shot size/eye line; light/time; exact dialogue ID and pronunciation; sound transitions; readable controlled text; and neighboring start/end state. A normal adult returns cleanly after stylized inserts. No fake notification implies real people joined, no actor/brand likeness slips into a prop, and no uncertain product delivery becomes a factual claim.
