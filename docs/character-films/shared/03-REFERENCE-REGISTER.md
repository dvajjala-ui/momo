## Reference priority

Owner's latest explicit character correction → actual accepted character/reference → accepted neighboring action/end state → this new detailed working proposal → older short-film prompt. A file's presence does not automatically mean it was approved. A failed/frozen/brand-marked take is not a safe next-frame anchor just because it looks attractive.

Do not recover and republish the removed unverified moodboard images from Git history as a shortcut. Their inspiration can be described, but likeness, costume, music and image rights are not established by a filename or a local copy. Original new scene art and actual permitted voices keep the planning separate from that unresolved material.
