## Practical next sequence

1. Read the character's bible and screenplay; choose outstanding outfit/voice/design details while keeping owner-established facts intact.
2. Prepare/attach only the actual relevant references. A described but unmade sheet is not an available asset.
3. Use the common identity block with one shot or a coherent small batch, one main action per take, preserving individual outputs.
4. Review real body/object movement, face/wardrobe/light continuity and exact spoken lines. Accept the first test before continuing the next batch.
