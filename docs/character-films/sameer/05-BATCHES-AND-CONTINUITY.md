# Sameer — editable batches and continuity

**Master plan:** 150 seconds. Five editorial batches, each cut from six separate timed shots. A batch is a change/review boundary, not a command to generate several complicated actions at once.

## B01 | 00:00–00:30 | A possibility and a normal no

**Shots:** SA01–SA06 (30-second draft edit).
**Voice IDs:** SA-L01, SA-L02, SA-L03.
**Entry state:** Saturday room K1, warm lamp/fan, shoes beside bed and backpack on chair.
**Exit state:** Supported recline after an ordinary friend reply; phone safely on chest.
**Prepare first:** Corrected sheet, room layout, original hobby inserts, fictional friend audio.
**Continuity risk:** Do not turn a normal refusal into cruelty or a permanently worried face.

**Review gate:** Play with scratch dialogue and again without sound. The main physical action and feeling must be readable in both. Compare the opening/ending state to the identity sheet: face, hair/headwear, skin, adult build, wardrobe, props and light. Check actual hand/foot contact, eye direction and breathing. A moving camera over a still does not count as performed action. Verify edited text separately and keep the same voice for the same pictured adult.

**Repair boundary:** Keep the previous take and version the replacement by shot ID. Change only the weak action, maintaining incoming/outgoing pose and enough sound handles for a clean cut. A changed duration updates this batch and all later time labels; it does not silently change spoken words or speed an actor. Record what wardrobe/prop/environment state changed so the next batch starts from the accepted state.

**Approval handle:** Review one representative identity-and-movement test before completing this batch. Mark draft/review/accepted/rejected explicitly. Only accepted footage moves forward; a detailed prompt is not evidence that a result exists.

## Change-impact map

| Change | Recheck | Usually reusable |
|---|---|---|
| Lead identity or silhouette | All repeated lead shots; supporting eye-lines | Independent edited graphics with compatible framing |
| Wardrobe/phone/bag prop | Every view that exposes that detail | Tight expressions without the changed prop |
| Date/venue/host/cost | Planning card, arrival and time-jump cues | Accepted generic home or field action if context still fits |
| Lead voice | All lead line cues and visible-mouth shots | Clean silent action/environment inserts |
| Supporting speaker | Their visible face shots and every repeated line | Lead reaction with unchanged timing |
| End copy | Last graphic and available reading hold | Living table/bench picture with sufficient empty space |

## Shorter and fuller variants

- Around 132 seconds: compress hobby inserts and packing hesitation, trim an environment hold, retain the normal refusal/wish/confirmation/first hello/shared joke.
- Around 165 seconds: add natural listening and a clearer details card, not a repeated frozen smile.
- Micro repair: replace one shot plus neighboring sound/pose handles, without regenerating all five batches.

## Records to keep

Per shot: exact ID, identity-reference version, wardrobe/daylight state, prompt version, raw duration, selected edit in/out, dialogue file ID, voice revision and acceptance note. Costs can be recorded only after an actual authorized generation; do not invent amounts or attach credentials. Retain previous accepted takes. No key belongs in these documents. A later owner-provided Cartesia connection can fill voice IDs after voice review; these writing files do not call it.
