# Dhwani — Garba ke baad

**Detailed long-form production brief** · 5 November 2026 · **Working runtime: 2:40 / 160 seconds** · **32 shots, six editable batches** · Original adult character, 24.

A dance round ends but Dhwani still wants the evening to continue. Her friends' separate departures are ordinary, so a small hunger joke, a clear public food plan and a thoughtful welcome give her a voluntary next step. Packing sticks, settling her gajra and making one practical journey turn a phone tap into action. The shared table offers names, food and a new little rhythm; the ending is a pleasant memory rather than a guaranteed gang.

The script expands the pulled short-film source into a deliberately slower character film over two minutes. The original premise is preserved; specific face/wardrobe details and the expanded scenes are working proposals awaiting review. No finished movie, voice recording, generated character sheet or approved real event is claimed by these documents.
