# Dhwani — batches, continuity and easy revision

**Working film:** Garba ke baad · **160 seconds / 2:40**, comprising 32 five-second edit slots. Batches are edit/approval units, not a command to render a whole batch in one expensive request. Generate or produce only as much as has been reviewed, keep accepted takes and revise the failing action. Do not publish, send invitations or change the site as part of this brief.

## Before B01 — design and performance sample

Approve one normal adult four-view reference, the exact clothes/props, one short voice sample, and the environment geography. The detailed face, palette and wardrobe in the character bible are proposals until reviewed. Do not pretend these inputs already exist. Build a still reference for the intended start pose if the first frame otherwise drifts. Record a version such as DH-DESIGN-v01, DH-VOICE-v01 and DH-ROOM-v01; they are project labels, not fabricated provider IDs.

## Running state ledger

| Category | Never silently change |
|---|---|
| Face/body | The same adult model, skin tone, jaw/nose/eye structure, hairstyle, glasses/jewellery and proportions. Energy changes through acting. |
| Wardrobe | One magenta/teal/orange outfit for this continuous evening. Gajra is adjusted, not replaced. |
| Main props | Two sticks become one packed sleeve in tote; one phone moves pocket→hand→pocket→optional photo hand; bottle and meal stay distinct. |
| Daylight | One after-midnight evening with lit public activity; no sunrise inserted mid-meal. |
| People | Supporting adults retain faces/wardrobes. Friends' own plans are ordinary, not personal rejection. |
| Product | Public-plan logistics and a voluntary interest action precede attendance. Interest is not a confirmed place or attendance proof. |
| Graphics | Readable text is composed deliberately. No fabricated real event/counts, client data, testimonials or live-service claims. |
| Follow-up | Any later outside group is separate, opt-in and for actual attendees; no hidden phone-number exposure. |

## Change-impact examples

- A new face or hair silhouette invalidates all visual references and needs a deliberate new design version; changing one line should not.
- A different garment colour requires revisiting every visible matching item, including reflections and held fabric, rather than recolouring one shot and ignoring later shots.
- Changing the fictional venue/time/cost touches the plan insert, invitation, arrival light and any follow-up copy. It does not authorise a real event or a message to anyone.
- Extending a line by 0.8 seconds can be solved with a reaction hold or audio bridge; do not speed up the whole voice track or make unrelated silent mouths flap.
- Removing an optional joke must preserve the prop handoff on either side. If a phone was put away in the removed shot, add that practical handoff elsewhere.

## Deliverable/version record per accepted shot

Record shot ID; design/wardrobe/environment version; start and intended end frame; exact prompt; raw and selected duration; dialogue cue IDs; accepted take; visible concerns; review date; and what changed. Keep old accepted take until the replacement has passed review. No generation-service name or account credential is necessary in the creative brief; cost/account execution records belong outside public story documents.

## Assembly lengths

The main edit is 160 seconds. A roughly 130–145-second revision can reduce the optional transition/gag slots while keeping the decision, logistics, actual arrival and shared-memory payoff. A 30–45-second derivative is a later edit, not permission to cut every contemplative pause from this film. Choose the final length from real performance and readable text, not an arbitrary stopwatch at the expense of speech.
